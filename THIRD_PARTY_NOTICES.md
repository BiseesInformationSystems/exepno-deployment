# Third-party components and notices

This repository contains deployment configuration and bootstrap helpers.
It references container images rather than redistributing their complete
source trees here.

Components referenced by the package include MongoDB, MinIO, Qdrant,
Nginx, Google's Kubernetes deployment tools and the usage-based billing agent.

Each component retains its own license and notices. An MIT license selected
for Bisees-owned deployment files does not replace those obligations or
license the private Exepno application source.

## Before customer publication

- Record exact release image digests and corresponding upstream versions.
- Preserve upstream license/copyright notices in reused source.
- Review obligations associated with the custom MinIO build and distribution.
- Preserve the relevant source/build provenance and provide required materials.
- Verify applicable rights for any model weights or bundled assets.

This file is a review checklist, not a completed license-compliance opinion.
Do not label all third-party components as MIT.
